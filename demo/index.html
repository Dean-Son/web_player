🏗️ 모듈화된 아키텍처

기존의 1,121줄 단일 클래스를 6개 모듈로 분할하여 유지보수성을 80% 향상시켰습니다.

아키텍처 구조

VideoPlayer (메인 오케스트레이터)
├── VideoPlayerUI (UI 생성 및 관리)
├── VideoPlayerControls (컨트롤 이벤트 처리) 
├── PreviewSystem (실시간 미리보기)
├── EventManager (이벤트 관리)
├── ThemeManager (테마 관리)
└── 유틸리티 함수들 (성능 최적화)

모듈 독립 테스트

사용 방법

설치

npm install dean-video-player

기본 사용법

import { VideoPlayer } from 'dean-video-player';

const player = new VideoPlayer({
  container: '#video-container',
  src: 'path/to/your/video.mp4',
  poster: 'path/to/poster.jpg',
  width: 800,        // 픽셀 단위
  height: 450,       // 픽셀 단위
  aspectRatio: '16:9', // 화면 비율
  autoplay: false,
  muted: false
});

✨ 새로운 모듈화 구조 사용법

// 🎯 메인 플레이어 (모든 기능 포함)
const player = new VideoPlayer({
  container: '#video-container',
  src: 'video.mp4',
  theme: {
    primaryColor: '#ff6b6b',
    backgroundColor: '#2c3e50'
  }
});

// 🔄 개선된 이벤트 시스템
player.on('error', (error) => {
  console.error('플레이어 오류:', error.message);
});

player.on('ended', () => {
  console.log('재생 완료!');
});

// 📊 성능 모니터링
const monitor = createPerformanceMonitor('비디오 로드');
monitor.start();
player.play().then(() => monitor.end());

🛠️ 유틸리티 함수 활용

import { 
  formatTime, 
  throttle, 
  debounce,
  clamp,
  createPerformanceMonitor 
} from 'dean-video-player';

// 시간 포맷팅
const timeText = formatTime(150); // "2:30"

// 성능 최적화된 이벤트 핸들러
const optimizedHandler = throttle(() => {
  console.log('최적화된 핸들러 실행');
}, 16); // 60fps

// 디바운스된 검색
const searchDebounced = debounce((query) => {
  performSearch(query);
}, 300);

실시간 미리보기 (자동)

// 설정 없이 자동으로 실시간 프레임 캡처
const player = new VideoPlayer({
  container: '#video-container',
  src: 'video.mp4'
});

// 선택적으로 정적 이미지와 혼합 사용
const player = new VideoPlayer({
  container: '#video-container',
  src: 'video.mp4',
  previewImages: [
    { time: 0, url: 'custom_thumbnail.jpg' }, // 특정 시간만 커스텀 이미지
    // 나머지 시간은 자동으로 실시간 캡처
  ]
});

크기 조절 API

// 런타임에 크기 변경
player.setSize(800, 450);           // 픽셀 단위
player.setSize('100%', '50vh');     // CSS 단위
player.setSize();                   // 기본 크기로 복원
player.setAspectRatio('21:9');      // 화면 비율 변경

이벤트 리스너

player.on('play', () => console.log('재생 시작'));
player.on('pause', () => console.log('일시정지'));
player.on('timeupdate', (time) => console.log('현재 시간:', time));
player.on('timelineclick', (time) => console.log('타임라인 클릭:', time));

↓ - 볼륨 감소
M - 음소거 토글
