사용 방법

설치

npm install dean-video-player

기본 사용법

import { VideoPlayer } from 'dean-video-player';

const player = new VideoPlayer({
  container: '#video-container',
  src: 'path/to/your/video.mp4',
  poster: 'path/to/poster.jpg',
  width: 800,        // 픽셀 단위
  height: 450,       // 픽셀 단위
  aspectRatio: '16:9', // 화면 비율
  autoplay: false,
  muted: false
});

크기 및 테마 커스터마이징

const player = new VideoPlayer({
  container: '#video-container',
  src: 'video.mp4',
  width: '100%',     // CSS 단위도 가능
  height: '50vh',    // 뷰포트 기준
  aspectRatio: '21:9', // 와이드 스크린
  theme: {
    primaryColor: '#ff6b6b',
    backgroundColor: '#2c3e50',
    textColor: '#ecf0f1',
    progressColor: '#e74c3c'
  }
});

실시간 미리보기 (자동)

// 설정 없이 자동으로 실시간 프레임 캡처
const player = new VideoPlayer({
  container: '#video-container',
  src: 'video.mp4'
});

// 선택적으로 정적 이미지와 혼합 사용
const player = new VideoPlayer({
  container: '#video-container',
  src: 'video.mp4',
  previewImages: [
    { time: 0, url: 'custom_thumbnail.jpg' }, // 특정 시간만 커스텀 이미지
    // 나머지 시간은 자동으로 실시간 캡처
  ]
});

크기 조절 API

// 런타임에 크기 변경
player.setSize(800, 450);           // 픽셀 단위
player.setSize('100%', '50vh');     // CSS 단위
player.setSize();                   // 기본 크기로 복원
player.setAspectRatio('21:9');      // 화면 비율 변경

이벤트 리스너

player.on('play', () => console.log('재생 시작'));
player.on('pause', () => console.log('일시정지'));
player.on('timeupdate', (time) => console.log('현재 시간:', time));
player.on('timelineclick', (time) => console.log('타임라인 클릭:', time));

키보드 단축키

Space - 재생/일시정지
← - 10초 뒤로
→ - 10초 앞으로
↑ - 볼륨 증가
↓ - 볼륨 감소
M - 음소거 토글
F - 전체화면 토글

🔧 테스트 및 디버깅

🔍 디버깅 가이드

  1. F12로 개발자 도구를 열어주세요
  2. Console 탭을 확인해주세요
  3. 위의 버튼들을 눌러 플레이어 상태를 확인해주세요
  4. 진행 바에 마우스를 올려보세요
  5. 콘솔에 나타나는 로그를 확인해주세요
  6. 오류가 있다면 빨간색 에러 메시지를 확인해주세요
예상 로그들:
  • 🎬 createPreviewVideo 시작
  • 📊 previewVideo 메타데이터 로드 완료
  • 🎯 showPreview 호출
  • ⚡ generateFramePreview 호출
  • 🎬 실시간 프레임 캡처 시작
